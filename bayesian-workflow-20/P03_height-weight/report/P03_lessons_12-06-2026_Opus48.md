# Lessons Report — Project 03: Height ~ Weight

**Author:** Truong Van Thien, PhD · **Date:** 12-06-2026 · **Model tag:** Opus48

## 1. The concept taught
The first **regression**: a Normal linear model `height = a + b·(weight − w̄)`. Two craft skills carry
forward to every later model — **centering** the predictor so the intercept means something, and
running the **prior predictive check on the slope**, where a careless prior silently implies impossible
people.

## 2. Workflow lessons from this run (with the actual numbers)
1. **Recovery first:** simulating with a = 155, b = 0.9, σ = 5 recovered all three (155.1, 0.93, 4.98)
   inside their 90% HDIs before any real data.
2. **The slope prior matters and the prior predictive proves it:** `b ~ Normal(0,10)` draws lines that
   slope *downward* and exceed 272 cm; `b ~ LogNormal(0,1)` keeps every line positive and human. You
   only see this by plotting the implied *lines*, not the prior on b.
3. **The result:** +1 kg ↔ **+0.90 cm** (94% HDI 0.83–0.99); intercept a = 154.6 cm at the average
   weight of 45 kg.
4. **A predictor shrinks residual spread:** σ fell from 7.8 cm (P01, no predictor) to **5.1 cm** here —
   weight explains a big share of height variation (correlation 0.75).
5. **Adding weight is decisively worth it:** LOO favours the linear model over intercept-only by
   `elpd_diff` = 147 with SE = 14.5 (**10 SE**); all Pareto-k̂ ≤ 0.15, so the comparison is trustworthy.

## 3. Common mistakes
- **Not centering**, then interpreting the intercept as "height at weight 0" — nonsense, and it also
  correlates a and b, hurting sampling efficiency.
- **Judging the slope prior on b alone.** `Normal(0,10)` looks innocuous until you draw the lines.
- **Extrapolating** the straight line beyond the adult weight range.

## 4. Try it yourself
1. Re-fit without centering and compare the intercept's meaning and the ESS.
2. Add children and use the PPC to expose where the line fails; propose a curve.
3. Build a 90% posterior *predictive* interval for a new 50 kg adult.

## 5. Self-check

2. Why is `b ~ Normal(0,10)` a bad prior here, and how does the prior predictive reveal it?
3. σ dropped from 7.8 to 5.1 cm between P01 and P03. What does that tell you?
4. `elpd_diff` = 147 with SE = 14.5. Is the linear model decisively better? How do you know?
