# Lessons Report — Project 02: A Single Proportion

**Author:** Truong Van Thien, PhD · **Date:** 12-06-2026 · **Model tag:** Opus48

## 1. The concept taught
Estimating **one proportion** with a Beta-Binomial model, and seeing that for a one-parameter problem
**grid approximation and MCMC give the identical posterior**. The deeper lesson is a cautionary one:
a *pooled* rate can be deeply misleading, which sets up Simpson's paradox in Project 07.

## 2. Workflow lessons from this run (with the actual numbers)
1. **Recovery first:** simulating `Binomial(1000, 0.38)` and fitting returned p̂ = 0.384 (90% HDI
   0.357–0.408) — truth recovered before any real data.
2. **Three methods, one answer:** posterior mean of p was 0.3877 (MCMC), 0.3879 (grid), 0.3879
   (exact conjugate `Beta`). For one parameter they coincide; MCMC earns its keep only when the
   parameter count grows.
3. **The pooled estimate is sharp but misleading:** p = 0.388 (94% HDI 0.375–0.403), yet the
   **department rates span 0.06 to 0.64** — a single p cannot fit them, as the Stage-8 plot shows.
4. **The apparent gender gap is real in the pooled data:** female 0.304 vs male 0.445. P07 will show
   this reverses once you condition on department — the data are the textbook Simpson's paradox.
5. **Prior-irrelevant by N:** power-scaling moved E[p] by < 0.0001 across α ∈ {0.5, 1, 2}; with 4526
   applications the likelihood dominates completely.

## 3. Common mistakes
- **Comparing groups with a pooled rate.** The pooled gender gap (0.30 vs 0.45) invites a causal
  story that the department-level data demolish.
- **Believing MCMC is "more accurate" than the grid here.** For one parameter the grid is exact;
  MCMC matches it. Neither is better — they answer the same integral.
- **Forgetting `sep=";"`** on a rethinking CSV.

## 4. Try it yourself

2. Fit a separate p per department and rank them.

   and write one paragraph on how the direction reverses.
