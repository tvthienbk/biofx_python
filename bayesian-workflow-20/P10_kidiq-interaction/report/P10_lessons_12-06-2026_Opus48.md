# Lessons Report — Project 10: Kid IQ (linear regression with an interaction)

**Author:** Truong Van Thien, PhD · **Date:** 12-06-2026 · **Model tag:** Opus48

## 1. The concept taught
The **interaction term**: in `score = a + b_hs·hs + b_iq·iq_z + b_int·hs·iq_z`, the effect of mother's
IQ **depends on** whether she finished high school. The craft skill is reading the interaction as **two
fitted lines with different slopes**, not as a single number.

## 2. Workflow lessons from this run (with the actual numbers)
1. **Recovery first:** simulating with a = 85, b_hs = 6, b_iq = 9, b_int = -4, σ = 18 (n = 800) recovered
   all five truths inside their 90% HDIs (85.3, 5.77, 8.14, -4.79, 17.97); R̂ = 1.00.
2. **Priors checked on the score scale:** the chosen priors imply kid_score 5–95% = **[35, 145]** —
   plausible, no negative or superhuman scores.
3. **The result:** the IQ slope is **+14.1 points per SD for children of non-HS mothers** but only
   **+7.3 for HS mothers** — the interaction `b_int = -6.83` (94% HDI **-11.23..-2.12**) is negative and
   credibly non-zero. The benefit of maternal IQ is larger where the mother did not finish high school.
4. **The main effect changes meaning with an interaction:** `b_hs` drops to **+2.95** (HDI -1.67..+7.05)
   because it is now the HS effect *at mean IQ*, not an average effect.
5. **LOO modestly prefers the interaction:** `elpd_diff` = **3.46 ± 2.70** (1.3 SE), stacking weight
   **0.95**, all Pareto-k̂ ≤ 0.15. The coefficient evidence is stronger than the LOO gap — report both.
6. **Prior is irrelevant:** power-scaling leaves E[b_int] at -6.86/-6.83/-6.78 across α.

## 3. Common mistakes
- **Interpreting `b_hs` as "the HS effect"** when an interaction is present — it is the effect *at the reference IQ* only.
- **Reporting one IQ slope** when the model says there are two (one per HS group).
- **Forgetting to standardize mom_iq**, which makes the intercept and interaction hard to read.
