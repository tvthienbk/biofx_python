# Lessons Report — Project 04: Divorce ~ Marriage + Age

**Author:** Truong Van Thien, PhD · **Date:** 12-06-2026 · **Model tag:** Opus48

## 1. The concept taught
The first **multiple** regression `D = a + bM·M + bA·A` on **standardized** variables. Two skills carry
forward: **standardization** (mean 0 / sd 1) so a `Normal(0, 0.5)` prior is weakly-informative and
coefficients are comparable across predictors, and reading a **DAG** (`M ← A → D`, `M → D`) to recognize
**confounding** — a predictor whose apparent effect is borrowed from a common cause.

## 2. Workflow lessons from this run (with the actual numbers)
1. **Recovery first:** simulating with a = 0, bM = 0.10, bA = −0.60, σ = 0.70 recovered all four
   (−0.024, 0.129, −0.617, 0.703) inside their 90% HDIs before any real data.
2. **The confound is in the EDA:** corr(M, A) = **−0.72** — marriage rate and age at marriage move
   together, so a raw M–D association (corr +0.37) is suspect.
3. **The headline result — confounding dissolves the effect:** `bM = +0.34` (94% HDI +0.10, +0.59) in
   `D~M` alone, but **`bM = −0.06` (94% HDI −0.36, +0.24)** once A is added. Meanwhile **`bA = −0.61`**
   (94% HDI −0.91, −0.31) is the durable driver — later marriage, less divorce.
4. **LOO confirms M is redundant:** `D~A` ranks first; the full `D~M+A` is tied with it
   (`elpd_diff` = **0.32 ± 0.53 SE**, under 1 SE), and `D~M` alone is worse (6.15 ± 4.98). Stacking puts
   weight 0.88 on `D~A`, 0 on the full model.
5. **Small-n honesty:** with 50 states, **max Pareto-k̂ = 0.91 > 0.70** — a few high-leverage states make
   LOO slightly optimistic; the ranking is robust but the exact elpd would benefit from `reloo`.
6. **Prior power-scaling barely moves bM, bA** (bM: −0.071 → −0.050; bA: −0.625 → −0.595 across
   α ∈ {0.8, 1.25}) — the conclusion is data-driven.

## 3. Common mistakes
- **Reading the raw M–D correlation as causal.** corr(M, D) = +0.37 is mostly the back-door path `M ← A → D`.
- **Not standardizing**, then using `Normal(0, 0.5)` priors — on raw rates those priors are nonsensical.
- **Trusting LOO blindly when Pareto-k̂ is high** (here 0.91); always check it against the threshold.
