# Lessons Report — Project 05: Vote share ~ economic growth

**Author:** Truong Van Thien, PhD · **Date:** 12-06-2026 · **Model tag:** Opus48

## 1. The concept taught
Hibbs's **"Bread and Peace"** model `vote ~ Normal(a + b·growth, σ)` fit to just **16 elections**. Two
skills: reading the **slope in plain units** (vote points per +1% growth), and building an honest
**posterior predictive interval** for a future election — which is much wider than the interval for the
*mean*, because it adds the residual election-to-election noise σ.

## 2. Workflow lessons from this run (with the actual numbers)
1. **Recovery first:** simulating with a = 52, b = 3.0, σ = 3.5 recovered all three (52.17, 2.87, 3.55)
   inside their 90% HDIs. (Tiny n makes the intercept weakly identified, so Stage 0 uses extra simulated
   rows — a lesson in itself about small samples.)
2. **The data are strongly linear:** corr(growth, vote) = **+0.76** across the 16 elections.
3. **The headline result:** each +1% of growth → **+3.05 vote points** (94% HDI 1.50, 4.45); at zero
   growth the incumbent gets a = **46.3%** (a flat economy favours the challenger). **P(b > 0) = 0.999.**
4. **Mean vs predictive intervals:** at growth = 2%, the *mean* vote 90% interval is [50.7, 54.1] but the
   *predictive* interval is **[45.5, 59.4]** — the extra width (≈ ±7 pts) is residual σ ≈ 4.1, the part of
   an election the economy does not explain. P(win) = 0.74 at 2% growth, 0.96 at 4%.
5. **Tiny-n LOO is fragile but usable here:** `growth` beats intercept-only by `elpd_diff` = **5.34 ± 3.63
   SE** (≈ 1.5 SE); **max Pareto-k̂ = 0.62 < 0.70**, so LOO is just reliable — but do not over-read it.
6. **Prior power-scaling barely moves b** (3.053 → 3.041 across α ∈ {0.8, 1.25}) — data-driven.

## 3. Common mistakes
- **Reading hibbs.dat with the default comma delimiter** — it is whitespace-delimited; use `sep=r"\s+"`.
- **Reporting only the mean interval** for a forecast, hiding the residual noise the voter actually faces.
- **Trusting a tiny-n LOO comparison as if n were large** — always show Pareto-k̂.

## 4. Try it yourself
1. Refit with a StudentT likelihood; does an outlier election (1952, 2008) move the slope?
2. Reproduce the mean and predictive intervals at growth = 0% and explain the width gap.
3. Add Hibbs's second predictor (military fatalities) and choose its prior.
