# Lessons Report — Project 15: Hurricanes (Gamma-Poisson; critical appraisal)

**Author:** Truong Van Thien, PhD · **Date:** 12-06-2026 · **Model tag:** Opus48

## 1. The concept taught
Two things at once: an **overdispersed count model** (NegativeBinomial / Gamma-Poisson, with a dispersion
parameter `alpha` a plain Poisson lacks), and **critical appraisal of a contested published result**. The
claim — Jung et al. (2014, *PNAS*): "feminine-named hurricanes are deadlier" — is re-analyzed and shown to
be **fragile**. The lesson: a result can look "significant" yet not be credible.

## 2. Workflow lessons from this run (with the actual numbers)
1. **Recovery first, with a NULL truth:** simulating `b_fem = 0` recovered **−0.012** — the model does not
   manufacture a femininity effect from nothing.
2. **Overdispersion is huge:** deaths have mean 20.7 but variance 1655; the fitted dispersion **alpha = 0.452**
   confirms a Poisson would badly under-state the spread.
3. **The effect is weak:** **b_fem = 0.212 ± 0.152**, 94% HDI **[−0.067, 0.495] crosses zero**, |b|/sd = 1.39.
   P(b_fem > 0) = 0.92 — suggestive but not decisive.
4. **It is influence-driven:** dropping one storm (Camille, 256 deaths) cuts b_fem from **0.212 to 0.132** — a
   third of the "effect" rests on a single data point.
5. **It fails the LOO test:** the intercept-only model **wins**; `elpd_diff` = 0.10 ± 1.56 = **0.06 SE**.
   Femininity buys no out-of-sample predictive power.
6. **The inference is calibrated (SBC p = 0.603):** so the weakness is in the *effect*, not the machinery —
   an honest distinction.

## 3. Common mistakes
- **Fitting a Poisson** and ignoring overdispersion — standard errors collapse and a spurious effect can look "significant."
- **Reading P(b > 0) = 0.92 as proof.** It is not: the HDI crosses zero, |b|/sd < 2, and LOO finds nothing.
- **Ignoring influential points.** A handful of catastrophic storms drive the apparent association.
- **Confusing in-sample fit with predictive value.** Only LOO (or held-out data) answers "does it help?"
