# Lessons Report — Project 16: Trolley (ordered-categorical / OrderedLogistic)

**Author:** Truong Van Thien, PhD · **Date:** 12-06-2026 · **Model tag:** Opus48

## 1. The concept taught
The **ordered-categorical** likelihood. A 1–7 moral-permissibility rating is ordinal: the levels have an
order but the gaps are not equal, so it is neither a count nor a continuous outcome. `OrderedLogistic`
places **6 cutpoints** on a latent logistic scale; a linear predictor `eta` shifts mass up or down the
scale. Two reusable skills: mapping `response 1..7 → 0..6` before fitting, and the **category-frequency
PPC** — comparing predicted vs observed frequency of each of the 7 levels.

## 2. Workflow lessons from this run (with the actual numbers)
1. **Recovery first:** simulating `bA = −0.7` recovered **−0.719** inside the 90% HDI.
2. **All three features lower permissibility:** **bA = −0.697, bI = −0.713, bC = −0.945** (odds multipliers
   0.50, 0.49, 0.39). Physical **contact** has the strongest effect.
3. **The category-frequency PPC is the right check:** predicted vs observed frequencies of all 7 levels match
   to within **0.003** — the model reproduces the whole distribution, including the mode at 4 (23.4%).
4. **The features earn their keep:** LOO favours the full model over cutpoints-only by `elpd_diff` = **382.3**
   with SE 27.6 (**13.8 SE**); max Pareto-k̂ = 0.06, so the comparison is trustworthy.
5. **Scaling worked:** the full model fit all **9930 rows in ~249 s** with 0 divergences — no subsampling needed.
6. **Calibrated (SBC p = 0.305).**

## 3. Common mistakes
- **Forgetting `response − 1`.** `OrderedLogistic` expects 0-indexed categories; passing 1–7 shifts everything.
- **Setting `initval=` on the ordered cutpoints variable.** In PyMC 5.28 that breaks `sample_prior_predictive`
  ("Cannot convert models with non-default initial_values"). Pass the ordered start via
  `pm.sample(initvals={"cut": ...})` instead.
- **Treating the rating as continuous** (a Normal regression) — it ignores the boundaries and the ordinal structure.
- **Using a mean/SD PPC** instead of the category-frequency PPC, which is the natural ordinal discrepancy.
