## This week in one sentence

When treatment is decided by whether a running variable crosses a known cutoff, units just above and just below the cutoff are comparable, so the jump in the outcome at the cutoff identifies a local causal effect — provided nothing else jumps there and no one can precisely manipulate which side they land on.
