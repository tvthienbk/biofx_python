## This week in one sentence

Prediction tells you what usually goes with what; causal inference tells you what would happen if you intervened — and the gap between them is created by confounding, reverse causation, and selection.

Problem Set 1 — spot the confounder/collider; Lab 0 — environment setup + GitHub + your first causal estimate.
